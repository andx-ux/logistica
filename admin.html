Что сейчас в галерее

Новые элементы появляются сверху. Стрелками меняйте порядок, ✎ — подпись, 🗑 — убрать с сайта.

Инструкция (один раз)

  1. Создать администратора. Откройте Firebase → Authentication → Users, нажмите Add user, в поле почты введите admin@gallery.rr-logistics.org (это внутренний адрес для логина admin, настоящая почта не нужна) и придумайте длинный пароль. В панель вы входите по логину admin и этому паролю.
  2. Разрешить работу с галереей. Откройте Firebase → Firestore → Rules, замените весь текст на приведённый ниже и нажмите Publish: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /logistica_gallery/{id} {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email == 'admin@gallery.rr-logistics.org';
    }
  }
}
  3. Фото: postimages.org → «Choose images» → после загрузки скопируйте «Direct link» (оканчивается на .jpg/.png) и вставьте сюда. Фото лучше до 2000 px по ширине.
  4. Видео: загрузите на YouTube, скопируйте ссылку из адресной строки и вставьте сюда.
  5. Пока в панели ничего нет, на сайте показываются образцы-заглушки. Как только добавите первый элемент, образцы пропадут.
