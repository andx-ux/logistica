# Как добавить фото и видео в галерею

Список для страницы галереи собирается **автоматически при каждой публикации сайта** — ничего запускать не нужно.

## Самый простой способ (без программ, только браузер)
1. Откройте https://github.com/andx-ux/logistica/tree/master/gallery/photos (для видео — `.../gallery/videos`).
2. Нажмите **Add file → Upload files**, перетащите файлы в окно.
3. Внизу нажмите **Commit changes**.
4. Через 1–2 минуты файлы появятся на сайте (`rr-logistics.org/gallery.html`) на обоих языках.

Удалить файл: откройте его на GitHub → значок «⋯» → **Delete file** → Commit.

## Правила
- **Фото:** jpg, png, webp. Лучше не больше 1–2 МБ и шириной до ~2000 px (снимки с телефона по 5–10 МБ замедляют сайт — уменьшите их заранее).
- **Видео:** mp4 (H.264) или webm. Через сайт GitHub можно загрузить файл до 25 МБ. Видео больше этого лучше выложить на YouTube (можно «по ссылке») и вписать адрес в файл `gallery/youtube.txt` (по одной ссылке в строке).
- Порядок — по имени файла (`01-...`, `02-...`).
- Подпись к фото/видео — необязательно, в файле `gallery/titles.json`:
  `{ "foto-1.jpg": "Yük konteynerə yüklənir", "foto-2.jpg": { "az": "Anbar", "ru": "Склад" } }`
- Обложка для видео: положите рядом картинку с тем же именем (`tur.mp4` + `tur.jpg`).

Фото `01.jpg` … `08.jpg` сейчас — **временные образцы** из шаблона; удалите их, когда загрузите свои.

(Если работаете в папке на компьютере: список можно обновить командой `node tools/build-gallery.js`, чтобы увидеть результат локально.)
