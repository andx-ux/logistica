# Как добавить фото и видео в галерею

Страница `gallery.html` читает список из `gallery/items.json`. Его не нужно править вручную:

1. Положите **фото** в папку `gallery/photos/` (jpg, png, webp), а **видео** — в `gallery/videos/` (mp4 или webm).
2. Выполните в папке сайта: `node tools/build-gallery.js` — список обновится.
3. Отправьте изменения на GitHub — Vercel сам обновит сайт (`rr-logistics.org`).

Порядок — по имени файла (`01-...`, `02-...`). Подписи к фото — по желанию, в файле `gallery/titles.json`:
`{ "foto-1.jpg": "Загрузка контейнера" }`.
Обложка для видео: положите рядом картинку с тем же именем (`tur.mp4` + `tur.jpg`).

**Большие видео** (больше ~50 МБ) лучше выложить на YouTube и вписать ссылку в `gallery/youtube.txt` (по одной в строке) — так сайт не тормозит, а GitHub не ограничивает размер.

Фото `01.jpg` … `08.jpg` сейчас — **временные образцы** из шаблона; замените их своими.
